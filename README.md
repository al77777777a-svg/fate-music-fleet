# أسطول 10 بوتات موسيقى لـ Discord

يتطلب Node.js `22.12.0` أو أحدث بسبب توافق Discord Voice Gateway الحديث.

قالب جاهز لتشغيل حتى 10 بوتات موسيقى من خدمة Railway واحدة. كل بوت لديه قائمة تشغيل واتصال صوتي مستقل داخل كل سيرفر.

## التشغيل على Railway

1. ارفع مجلد `work` إلى GitHub أو استخدمه كمصدر للمشروع.
2. في Railway أنشئ خدمة Node.js من المستودع.
3. أضف المتغير `BOT_TOKENS` وضع توكنات البوتات مفصولة بفواصل، بحد أقصى 10.
4. أضف `OWNER_IDS` اختياريًا: أرقام Discord للملاك مفصولة بفواصل.
5. أثناء الاختبار أضف `TEST_GUILD_ID` لتسجيل الأوامر فورًا في سيرفر واحد. احذفه عند الإطلاق العام.
6. ادعُ كل بوت إلى السيرفر، وأعطه في الروم الصوتي `View Channel`, `Connect`, `Speak`، وفي شات الأوامر `Send Messages`, `Embed Links`, `Read Message History`.

## الاستخدام

- اكتب `ش اسم الأغنية` أو `ش رابط` للتشغيل. الأوامر `play` و`p` و`شغل` تعمل أيضًا. الرسائل العادية مثل `aa` و`dd`، وأسماء الأغاني أو الروابط دون أمر، تُتجاهل تمامًا.
- يدعم البحث من YouTube، وروابط YouTube وSoundCloud، وروابط Spotify التي تُحوّل تلقائيًا إلى نسخة قابلة للتشغيل من YouTube.
- كل الأوامر والأزرار تعمل فقط في شات الروم الصوتي اللي أنت والبوت فيه. الشات العام والرومات الأخرى يتم تجاهلها حتى مع رقم البوت أو منشنه.
- إذا رومك بدون بوت، اكتب `join` داخل شات الروم الصوتي لاستدعاء بوت متاح، أو `1join` لاستدعاء بوت محدد غير متصل. بعدها استخدم أوامر التشغيل في نفس الشات.
- بدون رقم يرد بوت واحد من الموجودين معك في نفس الروم فقط. لتحديد بوت موجود في نفس الروم استخدم `1play` أو منشن البوت.
- `queue`, `nowplaying`, `pause`, `resume`, `skip`, `stop`, `clear`, `shuffle`, `loop`, `autoplay`, `volume`, `seek`, `filters`, `search`, `help`.
- `help` يرسل قائمة الأوامر في الخاص، ونتائج `search` يمكن اختيارها من الأزرار.
- رد التشغيل نص مختصر: `Playing song : اسم الأغنية by : اسم الطالب`. رد التخطي يذكر الأغنية التي تخطاها ومن طلب التخطي، ويظهر رد تشغيل مستقل للأغنية الجديدة. إذا انتهت القائمة، يطلب منك `ش اسم الأغنية`.
- رد تغيير الصوت يوضح النسبة القديمة والجديدة: `Volume changed from 50% to 150%.`
- `np` يعرض بطاقة التشغيل التفصيلية وأزرار التكرار وخفض الصوت والإيقاف المؤقت ورفع الصوت والتخطي وقائمة Filters.
- أعط البوت صلاحية `Attach Files` لإظهار أيقونة الميوزك في البطاقة.
- `play sc اسم الأغنية` يبحث مباشرة في SoundCloud. يهيئ البوت اتصال SoundCloud تلقائيًا، ويمكن إضافة `SOUNDCLOUD_CLIENT_ID` اختياريًا في Railway.
- إذا رفض YouTube تشغيل الصوت من عنوان الخادم، يحاول البوت نسخة SoundCloud مطابقة للعنوان والمدة، ويبيّن المصدر في رد التشغيل. إذا لم يجد تطابقًا، يعرض السبب ولا يدّعي بدء التشغيل. دعم روابط YouTube لا يضمن توفر البث حين يطلب المصدر تسجيل الدخول أو يمنع اتصال الخادم.
- تأكيد التشغيل ✅ وبطاقة Playing Song لا يظهران إلا بعد وصول مشغل الصوت إلى حالة Playing. الأغاني المنتظرة تُؤكّد برد فعل ✅ فقط.

## مهم

- لا تضع التوكنات داخل GitHub أو أي ملف. أضفها في Railway Variables فقط.
- لا تستخدم حسابات مستخدمين أو self-bots؛ هذا المشروع يعتمد على Discord Bot Accounts الرسمية.
- تشغيل YouTube/مصادر خارجية قد يتغير حسب سياسات المصدر. استخدم مصادر تملك حق تشغيلها.
- التخزين الحالي في الذاكرة، لذلك القوائم تعود فارغة بعد إعادة تشغيل الخدمة. يمكن إضافة Redis أو قاعدة بيانات لاحقًا لحفظ الإعدادات.
- الفلاتر تستخدم FFmpeg المضمّن في الحزمة؛ إذا منع مزود التشغيل سكربتات الحزم ستبقى الأغاني تعمل، لكن ستظهر رسالة عند اختيار فلتر.
