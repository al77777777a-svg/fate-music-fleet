# أسطول 10 بوتات موسيقى لـ Discord

يتطلب Node.js `22.12.0` أو أحدث بسبب توافق Discord Voice Gateway الحديث.

قالب جاهز لتشغيل حتى 10 بوتات موسيقى من خدمة Railway واحدة. كل بوت لديه قائمة تشغيل واتصال صوتي مستقل داخل كل سيرفر.

## التشغيل على Railway

1. ارفع مجلد `work` إلى GitHub أو استخدمه كمصدر للمشروع.
2. في Railway أنشئ خدمة Node.js من المستودع.
3. أضف المتغير `BOT_TOKENS` وضع توكنات البوتات مفصولة بفواصل، بحد أقصى 10.
4. أضف `OWNER_IDS` اختياريًا: أرقام Discord للملاك مفصولة بفواصل.
5. أثناء الاختبار أضف `TEST_GUILD_ID` لتسجيل الأوامر فورًا في سيرفر واحد. احذفه عند الإطلاق العام.
6. ادعُ كل بوت إلى السيرفر، وأعطه في الروم الصوتي `View Channel`, `Connect`, `Speak`، وفي شات الأوامر `Send Messages`, `Embed Links`, `Read Message History`.

## الاستخدام

- `play اسم الأغنية` أو `play رابط`، وكذلك كتابة اسم الأغنية وحده في شات الروم.
- يدعم البحث من YouTube، وروابط YouTube وSoundCloud، وروابط Spotify التي تُحوّل تلقائيًا إلى نسخة قابلة للتشغيل من YouTube.
- بدون رقم يرد البوت الموجود معك في نفس الروم فقط. لتحديد بوت معيّن استخدم `1play` أو منشن البوت.
- `queue`, `nowplaying`, `pause`, `resume`, `skip`, `stop`, `clear`, `shuffle`, `loop`, `autoplay`, `volume`, `seek`, `filters`, `search`, `help`.
- `help` يرسل قائمة الأوامر في الخاص، ونتائج `search` يمكن اختيارها من الأزرار.

## مهم

- لا تضع التوكنات داخل GitHub أو أي ملف. أضفها في Railway Variables فقط.
- لا تستخدم حسابات مستخدمين أو self-bots؛ هذا المشروع يعتمد على Discord Bot Accounts الرسمية.
- تشغيل YouTube/مصادر خارجية قد يتغير حسب سياسات المصدر. استخدم مصادر تملك حق تشغيلها.
- التخزين الحالي في الذاكرة، لذلك القوائم تعود فارغة بعد إعادة تشغيل الخدمة. يمكن إضافة Redis أو قاعدة بيانات لاحقًا لحفظ الإعدادات.
- الفلاتر تستخدم FFmpeg المضمّن في الحزمة؛ إذا منع مزود التشغيل سكربتات الحزم ستبقى الأغاني تعمل، لكن ستظهر رسالة عند اختيار فلتر.
